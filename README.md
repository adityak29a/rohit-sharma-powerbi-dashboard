# Rohit Sharma Career Statistics Analysis Dashboard

Interactive Power BI dashboard analyzing Rohit Sharma international cricket career performance across ODI, Test, and T20I formats from 2007 to 2025.

## Project Highlights

* Designed a dynamic sports analytics dashboard to visualize Rohit Sharma’s complete international cricket career.
* Created KPI cards for Total Innings (271), Total Runs (11,516), Batting Average (46.43), and Strike Rate (92.78).
* Built format selection filters for ODI, T20I, and Test match performance comparison.
* Developed year-range slicer for interactive analysis from 2007 to 2025.
* Created year-wise runs trend chart to identify peak scoring seasons and consistency.
* Designed boundary distribution donut chart for Fours (1083) and Sixes (355).
* Built milestone trend visuals for yearly 100s and 50s performance.
* Applied data modeling and relationships for accurate aggregations across formats.
* Used Power Query for data cleaning, transformation, and preparation.
* Implemented interactive slicers, filters, and responsive visuals for user-driven insights.
* Created a professional dark-themed dashboard layout with strong visual storytelling.

##  Analytical Value

* Demonstrates KPI reporting and dashboard design skills.
* Shows trend analysis, comparative analytics, and performance tracking.
* Highlights ability to convert raw sports data into actionable insights.
